# 07 · 引擎随机箱清理（除了预设点位，场上不出现自然随机箱）

> 效果：本图只认自己在预设点位刷的箱子（`boxN1` / `boxN2`、`center1~center6`），
> **场上不会出现任何引擎自然刷新的随机箱子**（含迷雾箱、金钱箱）。
> 真源：`scripts/lua/chouka/07_crates.lua`，节点「抽卡hex / 随机箱清理」（每帧、常驻）。

---

## 1 DSA 是怎么做的（照抄来源）

《DSA 自走棋》`lua/GAME/PureDraw/06_init_mcv.lua` 第 43–79 行，**两段延迟删除**：

```lua
-- ① 第 1 tick：只删"刷箱子的东西"
SchedulerModule.delay_call(function()
    local crateFilter = CreateObjectFilter({ IncludeThing = { "GenericCrateSpawner" } })
    local units, count = ObjectFindObjects(nil, nil, crateFilter)
    if count <= 0 then
        return
    end
    for j = 1, count, 1 do
        ExecuteAction("NAMED_DELETE", units[j])
    end
    -- 此外假如检测到随机宝箱，就默认启用旧抽卡模式。
    if g_DrawMode == nil or g_DrawMode == 0 then
        g_DrawMode = 1
        g_LuckyCrateMode = 1
    end
    if not g_HextechCountManuallySet then
        g_HextechCount = 3
        ...
    end
end, 1, {})

-- ② 第 45 tick：连"已经刷出来的实体箱子"一起删
SchedulerModule.delay_call(function()
    local crateFilter = CreateObjectFilter({
        IncludeThing = { "GenericCrateSpawner", "UnitCrateNew", "ShroudCrate", "MoneyCrateMP" }
    })
    local units, count = ObjectFindObjects(nil, nil, crateFilter)
    for j = 1, count, 1 do
        ExecuteAction("NAMED_DELETE", units[j])
    end
end, 45, {})
```

这段代码被编进 DSA 的地图节点 **`GAME/UtilsLuckyCrate`**（`EvaluationInterval=0` 每帧、`DeactivateUponSuccess=true`、payload ≈61 KB）。
作者原注释（源码注释被移到 `analysis/地图注释说明文档.md:2051`，附录 A.48.2）：

```
-- 箱子模式：只允许抽卡，不允许在地图上刷随机箱子（万一被 AI 捡了太麻烦）
-- 这个检测也是「局外「开启随机箱子」→ 默认开启抽卡 / 默认开启海克斯（三个）」的唯一读取入口
```

### 为什么要两遍

| 时机 | 干什么 | 为什么 |
|---|---|---|
| 第 1 tick | 删 `GenericCrateSpawner`（引擎的**刷箱器**） | 刷箱器没了 → 引擎之后**不再往图上刷**箱子 |
| 第 45 tick | 再扫一遍，把 `UnitCrateNew` / `ShroudCrate` / `MoneyCrateMP` 等**已经落地的实体箱子**删掉 | 第 1 tick 只能拦住"之后"的刷新；开局那一批实体箱子已经生成了，必须靠第二遍清 |

顺便：第 1 tick 那次"有没有找到 spawner"被 DSA 当成**大厅有没有勾「开启随机箱子」的唯一探针**（找到 → 默认开抽卡 + 默认海克斯 3 次）。本图也把这个探针留下了（`CHOUKA_LOBBY_CRATE_ON`），以后要联动别的系统可以直接用。

## 2 本图的实现（`07_crates.lua`）

### 2.1 时序

| 帧 | 动作 |
|---|---|
| **1** | 删 `GenericCrateSpawner`（全部）→ 之后引擎不再刷箱；删到就置 `CHOUKA_LOBBY_CRATE_ON = 1` |
| **45** | 先再清一遍生成器，再扫 5 种自然箱 → **离预设点位 80 以内的放过**，其余删掉；删到就在公屏报一句 |
| 之后 | 前 2 分钟（≤7200 帧）每 600 帧（≈10 秒）兜底补扫一次，防止某些箱子比开局动画还晚落地 |

节点 `EvaluationInterval = 0`（每帧）、`DeactivateUponSuccess = false` —— **不能设成一次性**，
否则第 1 帧成功后节点自我停用，第 45 帧那遍就永远跑不到。

### 2.2 删哪些、留哪些

删（`CHOUKA_CRATE_NATURAL` + `CHOUKA_CRATE_SPAWNER`）：

| 类型 | 说明 |
|---|---|
| `GenericCrateSpawner` | 引擎的随机箱**生成器** → 永远删，**不看保留点位**（留着它就一直刷） |
| `UnitCrateNew` | 原版单位箱（随机箱主要实体） |
| `UnitCrate` | 原版单位箱（旧模板名） |
| `ShroudCrate` | 迷雾箱 |
| `MoneyCrateMP` | 原版金钱箱 |
| `MoneyCrate` | 原版金钱箱（旧模板名） |

前 4 个（生成器 + `UnitCrateNew`/`ShroudCrate`/`MoneyCrateMP`）是 DSA 的原表，后两个是同一箱族里的旧模板名。

**绝对不删**的两种（加进去会直接把玩家的箱子干掉）：

| 类型 | 为什么不能删 |
|---|---|
| `LuckyUnitCrateSeed` | 抽卡技能（`SpecialPower_LuckyUnitCrate`）扔出来的可拾取箱子，本图抽卡的入口对象 |
| `moneycrate` | 本图自己的金钱箱（`02_private_box.lua` / `06_center.lua` 刷的） |

### 2.3 「保留点位」判断

模板名大小写不敏感时 `moneycrate` 和 `MoneyCrate` 可能是同一个东西 —— 为了**绝不误删自家箱子**，
删除前多一道几何判断：箱子离下面任一航点 ≤ `CHOUKA_CRATE_KEEP_RANGE`（80 世界单位）就放过。

```
box1~box6（老写法兜底）   box11 box12  box21 box22  box31 box32
box41 box42  box51 box52  box61 box62   center1~center6
```

自家箱子永远是 `CREATE_UNNAMED_ON_TEAM_AT_WAYPOINT` 直接刷在航点上（偏差 ≈0），
而引擎随机箱落在刷箱器附近，两者不会撞。点位两点之间相距约 70，所以半径 80 既够容住自家箱、
又不至于把旁边的引擎箱一起放过。

## 3 进游戏怎么验

1. **大厅勾上「开启随机箱子」**（有这选项的话），开一局。
2. 开局公告期间 / 开局后，**全图都看不到随机箱**（尤其刷箱器原来所在的角落）。
3. 公屏可能出现一句「已清除 N 个引擎随机箱子（本图只在预设点位刷箱）」。
4. **自家箱子必须还在**：
   - 开局后 120 秒 `boxN1` / `boxN2` 各刷一个金钱箱（每人两个）；
   - 每回合 `center1~center6` 各刷一个金钱箱；
   - 抽卡技能扔出来的箱子能正常捡、正常开。
5. 若发现某个自家箱子被误删：把它的类型从 `CHOUKA_CRATE_NATURAL` 去掉，
   或把它的航点加进 `CHOUKA_CRATE_KEEP_WPS`。

### 不确定项

| 项 | 说明 |
|---|---|
| `GenericCrateSpawner` 是否就是日冕的随机刷箱器 | 按 DSA 作者注释 + 命名推断；如果删了它箱子照刷，说明刷箱走的是别的路径，需要在游戏里再找类型名 |
| 45/600/7200 帧这几个数 | 按"每帧求值"估的（60 帧 ≈ 1 秒）。若发现 `EvaluationInterval = 0` 不是每帧，按实际倍数调整 |
| `MoneyCrate` / `moneycrate` 是否同一模板 | 正因为不确定才加了「保留点位」判断，两种情况下都不会误删自家箱 |
