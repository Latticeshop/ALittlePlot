# 02 · ALittlePlot 缝合方案（讨论稿）

> 目标：**以《[cor]每人一小块地(海域有限)2.0》为地图模板，缝进《盲盒高原》的抽卡经济，缝进《DSA_ggz自走棋》的海克斯符文系统。**
>
> 本文只讨论**方案**，不写实现。凡是标了 ❓ 的地方都是需要你拍板的岔路口。
> 三张源图的机制拆解见 `01-三张源地图机制拆解.md`，地图底座已经改了的地方见 `03-地图底座改造记录.md`。

## 1 先把「要缝什么」说清楚

三张图各给一样东西，而且**给的层级不重叠**：

| 来源 | 提供什么 | 在我们这里扮演的角色 |
|---|---|---|
| 一块地 2.0 | **地图拓扑 + 即时战略骨架** | 底座：6 岛 + 中心岛 + 海（已改造） |
| 盲盒高原 | **「随机奖励物」的出现节奏** | 经济层：把「矿场/油井→采集」换成「箱子→争夺」 |
| DSA 自走棋 | **「三选一永久强化」的决策层** | 成长层：把「攀科技造兵」叠上一层肉鸽强化 |

所以这张图最终是三层：

```
┌─────────────────────────────────────────────┐
│ L3 海克斯层  DSA 的符文：定时三选一，永久生效    │  ← 决策 / 成长
├─────────────────────────────────────────────┤
│ L2 盲盒层    箱子点位 + 刷新节拍 + 争夺规则      │  ← 经济 / 节奏
├─────────────────────────────────────────────┤
│ L1 地图层    6 岛 + 中心岛 + 共享外海 + 内海      │  ← 已改造完成
└─────────────────────────────────────────────┘
```

**关键取舍**：盲盒层是**实时**的（箱子随时刷、跑过去抢），海克斯层必须是**离散**的
（到点三选一，不能战斗中随时弹）。这两层的时间感天然不同，
**下面第 3 节要解决的「轮」就是让它们共用一个心跳。**

## 2 L1 地图层（已落地，这里只讲它带来的玩法后果）

改造细节见 `03`。这里只讲**新地形对设计意味着什么**：

| 改造 | 玩法后果 |
|---|---|
| 外圈 6 块海并成 **1 片共享外海**（249,828 格） | 6 个岛的海军**第一次能互相摸到**。海军从「自家泳池」变成「公共高速路」，海权第一次成为一个真议题 |
| 内圈 6 块海**原样隔断**（各 ≈14.7k 格，一格没变） | 每个玩家岛同时接触 **2 块内海**，每块内海只被**相邻两个岛**共享 → 天然形成 **6 组「二人决斗塘」** |
| 矿场 / 油井全删 | 收入 100% 由脚本给 → 经济曲线完全可调，这正是要缝盲盒的前提 |
| 中心岛仍在（中立、四周环水） | 唯一的**两栖/海军登陆争夺点**，天然的「大盲盒」位 |

> **这里有个很漂亮的巧合值得指出**：你要的「6 小块地围绕中心连通 + 与隔壁小岛俩俩连接」，
> 在新地形上是**同时成立**的 ——
> **外海**让 6 个岛围绕中心彼此连通（人人可达）；
> **内海**让每个岛与左右两个邻居各有一条「私属水道」。
> 也就是说地形本身已经给出了两种「距离」：**远邻打海，近邻打塘**。
> 后面 L2/L3 的点位设计可以直接吃这个结构。

❓**Q1**：中心岛要不要**加一条陆桥**（只连内海/不连岛，做成两栖跳板）？
现在中心岛必须靠海空力量才能上，如果海克斯里有「陆军强化」类符文，陆军在中心岛是用不上的。
三种选择：① 保持孤岛（纯海空争夺）② 加一条通往某一内海的浅滩（两栖可行）③ 中心岛改成「只能靠空投/传送进入」。

## 3 核心难题：一块地没有「回合」，海克斯怎么触发？

这是整个缝合里**唯一真正的结构性问题**。DSA 的海克斯整套流程挂在一个心跳上：

```
回合开始 → OnRoundBegin(lvc) → 是否发放回合？ → 入队 → 按 J 展开 → 选 → 登记到回合回调 → 每回合出兵时上 buff
```

一块地**没有回合**（它是普通 RTS，只有秒表），也**没有「每回合出兵」这个时刻**可挂 buff。
所以要拆成两件事分别解决：**① 心跳怎么来　② 效果怎么施加**。

### 3.1 心跳（「轮」）的三种做法

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A 秒表轮** | 全局计数器 `lvc` 每 60 秒 +1，所有「每 N 轮」的逻辑（海克斯发放、科技解锁、箱子节拍）都读它 | 实现最简单；和 DSA 代码结构 1:1；玩家可预期 | 节奏死板；和战况无关，顺风逆风都同一时间发卡 |
| **B 事件驱动** | 达到条件才发（击毁 N 个单位 / 抢到 K 个箱子 / 推掉一座建造工厂） | 奖励技术；顺风早发逆风晚发，天然追赶 | 雪球风险；和 DSA 的 UI/事件时机不兼容；难平衡 |
| **C 混合** | 秒表轮当**保底心跳**，另加**可选的「抢箱加速」**：抢到中立箱额外给 1 次重随/提前一档稀有度 | 兼具 | 规则变多，违背小块地「少规则」的初衷 |

> **推荐 C 的简化版 = A + 一个小奖励**：心跳固定 60 秒一轮；
> 海克斯在第 **3 / 8 / 13 / 18** 轮发放（≈ 3 分 / 8 分 / 13 分 / 18 分），
> 稀有度概率沿用 DSA 的第 1/2/3/4 发那套（10/40/50 → 15/42/43 → 15/42/43 → 30/50/20）。
> 「抢到中立箱」不直接加发卡次数（避免雪球），而是**给本次三选一多加一次重随机会**。
>
> 为什么是 4 次而不是 DSA 的前 3 次？因为一块地一局通常 10~25 分钟，5 分钟一次刚好 4~5 次决策点；
> 太少（1~2 次）玩家感觉不到「肉鸽」，太多（>5 次）会稀释选择权重。

❓**Q2**：一轮多少秒？我建议 **60 秒**。也可以「前 5 轮 45 秒、之后 60 秒」让开局更快进入状态。
❓**Q3**：海克斯发放次数：**固定 4 次**（不提供 0~4 的房主可调），还是保留 DSA 那样的房主可调？
小块地图的惯例是「打开就能玩」，我倾向前者。

### 3.2 效果怎么施加（比心跳还关键）

DSA 的符文效果里有一大半是「**每回合出兵时**给该玩家新建的单位上 `AttributeModifier`」。
一块地没有这个时刻。三条路：

| 方案 | 做法 | 评价 |
|---|---|---|
| **A 符文 = 隐藏升级（Upgrade）** | 每张符文对应一个 `AttributeModifierUpgrade`，选中即 `PLAYER_GRANT_UPGRADE` 永久授予 | ⭐ **推荐**。RA3 的升级天然对新造单位生效、永久、可叠加、不需任何「出兵时刻」，且对 AI 同样有效 |
| B 符文 = 定时轮询上 buff | 每秒扫描全图己方单位，缺 buff 的补上 | 性能差、容易漏、单位一多就卡；只在 A 表达不了的效果上兜底 |
| C 符文 = 一次性脚本效果 | 发钱、空投、开图、召唤 | 和 A 并存，用于「非属性类」符文 |

**结论**：海克斯池**按「能不能做成升级」重新分类**：

| 类 | 能否做成 Upgrade | 例子 |
|---|---|---|
| 属性类（攻/防/速/血/射程/造价/建造速度） | ✅ 能 | 「步兵 +20% 血」「载具 -15% 造价」「海军 +2 视野」 |
| 经济类 | ⚠️ 部分 | 收入倍率做不了升级 → 走脚本改成「每秒给钱」的分档 |
| 情报类（开图/雷达/侦察） | ⚠️ 部分 | 开图走脚本；雷达提示走脚本 |
| 召唤/一次性类（空投、召唤、协议解锁） | ❌ 不能 | 走脚本 + `GRANT_UPGRADE` 解锁协议 |
| 规则改写类（DSA 的「变形重组器」「以战养战」） | ❌ 不能 | **建议不要移植**，它们强依赖自走棋的单位池 |

> 一句话：**DSA 的池子不能直接搬，要照着一块地的兵种表和 RA3 的升级能力重写一遍池子。**

❓**Q4**：接受「符文 ≈ 永久升级」这个口径吗？如果接受，池子的形态会和 DSA 的**长得像但内容完全不同**（更像 LoL 的小符文页而不是斗魂竞技场）。

## 4 L2 盲盒层设计

### 4.1 三类箱子（吃上面「两种距离」的结构）

| 类型 | 对象 | 位置 | 归属 | 刷新 | 设计意图 |
|---|---|---|---|---|---|
| **私有箱** | `unitcratenew` | 每个玩家岛上 2 个固定点（航点 `h1..h12`，每人 2 个） | 该玩家 | 每 N 秒 | 保底：不看地图也不会断档 |
| **决斗箱** | `moneycrate` | 6 块**内海**各 1 个（海上） | 中立 `PlyrCivilian` | 每 N 秒 | 让相邻两岛有理由为海上资源动手（吃掉「俩俩连接」的设定） |
| **大争夺箱** | `moneycrate` ×2 + 一个特殊奖励 | 中心岛 4 个角 | 中立 | 每 N 秒，且**开局延迟** | 全场公共目标，对应原图的中心油井 |

> 中心岛原来油井的「重建」逻辑（`油田重铸` 脚本组，现在已停用）正好可以复用：
> 把「重建油井」换成「重刷中心盲盒」，脚本骨架一模一样，只换 `ObjectName_1`。

### 4.2 刷新节拍

盲盒高原用的是「一个 `EvaluationInterval=120` 的全局脚本，每结算一次就把所有箱子重新生成」。
问题是：**如果箱子没被拿走，重复生成是不是会叠一堆箱子？**
盲盒高原的做法是**先删后建**还是靠引擎的「同名箱子只存在一个」，需要实测确认 ——
建议我们采用**明确的「先 `NAMED_DELETE` 再建」**：
每个箱子点位都给一个命名（`mbx_p{玩家}_1` 之类），节拍到点先删同名再重建，行为完全确定。

❓**Q5**：刷新节拍多久？我建议：私有箱 **90 秒**、决斗箱 **60 秒**、中心大箱 **150 秒**且开局 **3 分钟**才第一次刷。
（三个不同的节拍能让地图上有持续的小事件流，而不是一次全刷完。）

### 4.3 经济总账

砍掉矿场油井之后，收入只有三处：`Money` 脚本（MCV 数量）、私有箱、争夺箱。

- 保留原图 `Money`：**有展开的建造工厂 → $8/秒**（原图口径，不用改）。
- 箱子给钱量建议和 DSA 的「电厂=收入」对齐：一局 15 分钟，正常收入 ≈ $8/s × 900s = 7200 + 箱子。
  箱子单价建议 **$300~$800** 随机（引擎的 `moneycrate` 自带随机额，实测确认后再定）。

❓**Q6**：`Money` 的基础收入要不要上调？原图是「一岛一个 MCV → $8/s」的节奏；
现在矿没了，玩家会更依赖箱子，我建议把基础收入提到 **$10~12/s** 并让箱子更值钱。

## 5 L3 海克斯层设计

### 5.1 要搬 DSA 的什么

| DSA 组件 | 搬不搬 | 说明 |
|---|---|---|
| 稀有度三档 + 概率表 | ✅ 搬 | 银/金/彩，边框素材直接复用 |
| 三选一卡面 UI（`exCreateCustomButtonForPlayer` + webp 边框 + relics 图标） | ✅ 搬 | 素材路径见 DSA 文档 5.0.2 |
| 「按 J 展开、不自动弹」 | ✅ 搬 | 战斗中弹窗对一块地是灾难 |
| 每人独立筛池 + 无放回 + 每人独占 | ✅ 搬 | 防止 6 个人拿到同一张 |
| 不重复名单（`NonRepeatableRuneIds`） | ✅ 搬 | |
| 顶部按钮「查看已持有符文」面板 | ✅ 搬 | |
| 公共面板播报「玩家X获得符文Y」 | ✅ 搬 | 一块地是明牌对局，播报很有价值 |
| 兵种四展开（步/载/飞/海） | ✅ 搬 | 一块地的海军现在很重要，海/陆/空分家有意义 |
| 阵营限制（`RequiredFaction`） | ⚠️ 视情 | 一块地可能允许随机阵营，限制卡会造成「抽到废牌」 |
| 禁用模式过滤（禁海/禁飞等） | ❌ 先不做 | 一块地没有这些模式开关 |
| 每回合出兵上 buff | ❌ **改成永久 Upgrade** | 见 3.2 |
| 自走棋专属卡（变形重组器/以战养战/究极生物/缩小射线…） | ❌ 不移植 | 强依赖单位池与回合制 |

### 5.2 池子框架（建议 36~45 张起步）

| 类 | 银 | 金 | 彩 |
|---|---|---|---|
| 经济（收入 / 箱子收益 / 造价） | 4 | 3 | 2 |
| 生产（建造速度 / 队列 / 维修） | 3 | 3 | 2 |
| 陆军（步 / 载 / 空 三档各若干） | 4 | 4 | 3 |
| 海军（造船速度 / 射程 / 抗性 / 反潜） | 4 | 4 | 3 |
| 情报 / 侦察（开图 / 雷达 / 视野） | 3 | 2 | 1 |
| 特殊（空投、协议解锁、一次性大招） | 2 | 3 | 3 |

> 设计原则：**银=数值小加成，金=改写玩法的小规则，彩=改变局势的大件**。
> 银卡每张只动一个数（+15% 血），彩卡每张都要让玩家「哇」一声（例如「全场船只获得免费维修无人机」）。

### 5.3 与「决斗塘」联动的独占设计（建议新增）

因为新地形给了 6 组「相邻两岛共享一块内海」的结构，可以做一件 DSA 做不到的事：

> **内海主宰（彩）**：当你的海军独占一块内海（该内海里没有邻居的船）时，获得额外效果（例如收入 +20% / 造船速度 +30%）。
> **邻居镜像（金）**：你获得一张与你左邻已持有的某张银卡同类的复制（体现「俩俩相连」）。

这类「贴着地图结构长出来的符文」是这张图的差异点，比单纯搬 DSA 的池子有意思得多。

❓**Q7**：要不要做这类「吃地图结构」的专属符文？工作量会增加，但它是这张图区别于 DSA 的记忆点。

## 6 技术栈与分工

| 层 | 技术 | 理由 |
|---|---|---|
| L1 地图 | Ra3MapEditor MCP（已完成） | — |
| L2 盲盒 | **原生触发器** | 盲盒高原已验证；点位固定、逻辑简单、不依赖任何 DLL |
| 心跳（轮） | **原生触发器** + Lua 只读计数器 | 计数器与计时器是原生触发器最强的部分 |
| L3 海克斯 | **Lua 4.0 bridge（`#!ra3luabridge`）** | 池子/去重/UI/状态太多，纯原生会变成成百上千个计数器 |
| 房主选项 | **Lua**（DSA 的 `BtnChoiceDialogEventFunc` 那套） | 复用 |

**这个分工还带来一个好处**：如果某台机器没有 `Ra3LuaPlatform.dll`（海克斯必须依赖它），
地图会**降级成「一块地 + 盲盒」**照常能玩，不会直接崩。

### 6.1 必须记住的 Lua 4.0 硬约束（照抄 DSA 的踩坑记录）

1. Lua **4.0** —— 没有 `goto`、位运算、`table.unpack`
2. **闭包不能访问外层局部变量** —— 回调参数化或提升为全局
3. 每个块必须 `#!ra3luabridge` 开头
4. 单 payload **≈64KB** 上限，超了截断并报 `<eof>`；超 64512 B 时工具链自动去注释，仍超就必须**先在地图脚本树里加节点**再拆
5. `t[nil]` 会直接抛错，查表前必须判空
6. `lua/` 源文件 → `ScriptsData.json` → 地图脚本树三处要同步，别手改中间件
