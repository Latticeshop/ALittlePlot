## 1 先说 DSA 是怎么实现的（带证据）

DSA 的开局不在某一个 Lua 文件里，而是**地图脚本节点 + Lua 回调**接力跑完的。
下面每一条都能在 DSA 工程里对到原文：

### ① 锁视角 + 弹公告（进游戏第 0 帧）

| DSA 位置 | 做了什么 |
|---|---|
| 节点 `text/0`（int=0，一次性） | 5 条 `TextDoActionLocalized("NAMED_SHOW_INFOBOX", ...)` 给 `up/down/re/t533/t534` 挂信息框；动作链里有 **`MOVE_CAMERA_TO(CAM0,0,0,0,0)`** —— 把全体相机瞬间钉到地图中心航点 `CAM0` |
| 节点 `text/camera`（int=0，常驻） | `CAMERA_FOLLOW_NAMED(re,1,700)` —— 相机跟住中心那个具名物体，等效"锁死视角" |
| `lua/text/Update_0.lua:47` | **`exShowLongTextDialog(1, 群号+规则全文, '', "已阅读", "更新日志")`** —— 全屏长文本公告，3 个按钮里第 1 个传空串就隐藏 |
| `lua/text/Update_0.lua:49-80` | `onUserLongTextDialogEvent(playerName, btnIndex, dialogId)`：**btnIndex==2（已阅读）** 时 → `CREATE_NAMED_ON_TEAM_AT_WAYPOINT(playerName,'AlliedWallPiece',...,'toupiaodian'..o)`，即"投一票我已读完"，并 `exCustomBtnRemoveForPlayer` 收掉语言按钮 |

> 人机不用点：`text/Human` 节点给每个 AI 位也生成一个投票点（`PLAYER_IS_HUMAN_OR_AI_PERSONALITY` 判断）。

### ② 房主选择模式

| DSA 位置 | 做了什么 |
|---|---|
| 节点 `text/close_Update`（int=0，一次性）**条件 = `NAMED_NOT_DESTROYED(Player_1) && … && NAMED_NOT_DESTROYED(Player_6)`** | 六个投票点都在 → 代表"大家都点了已阅读" |
| 同上，Lua payload（= `lua/text/ChooseMode.lua` 全文） | `exMessageAppendToMessageArea(Localization.get("dialog.choose_mode.waiting"))`（"等待房主选择游戏模式"）→ 移除语言按钮 → **认房主** → `BtnChoiceDialogEventFunc_ShowGameModeDialog(g_RoomOwnerPlayer)` |
| `lua/GAME/GetRoomOwnerPlayer.lua` / `lua/text/ChooseMode.lua:15-20` | 认房主的办法：`SetWorldBuilderThisPlayer(1)` → `CopyPlayerRegisteredObjectSet("<1st Human Player>", "STRUCTURES")` → `ObjectTeamName(structures[1])` → 用 `g_objectTeamNameToPlayerName` 把 `teamPlayer_N` 换成 `Player_N` |
| `lua/LUABOX/BUTTON/BtnChoiceDialogEventFunc.lua:771` | `BtnChoiceDialogEventFunc_ShowGameModeDialog(playerName)`：只给房主开一个 `exShowCustomBtnChoiceDialogForPlayer`（最多 7 个竖排按钮），选项上带"（已选）"，勾完才出现"确认"按钮 |
| 同上 `:1321-1332`（确认分支） | 播报开局信息 → `exAddTextToPublicBoard(beginLines, 15)` → **`exEnableWBScript("readyForStartCam")`**（放行下一段） |

### ③ 正式开始（运镜 → 交还操作）

| DSA 位置 | 做了什么 |
|---|---|
| 节点 `cams/starts` | `HIDE_UI()` + `CAMERA_LETTERBOX_BEGIN()` + **`DISABLE_INPUT()`** + `MOVE_CAMERA_TO(...)` + `PLAYER_CAMERA_MOVE_TO(Player_N, 511/611, ...)` —— 就是作者说"不要"的那段运镜 |
| 节点 `cams/cam4` | `SHOW_UI()` + **`LOCK_CAMERA(0)`** + **`ENABLE_INPUT()`** + `PLAYER_ENABLE_BASE_CONSTRUCTION(<All Players>)` + `PLAYER_SET_MONEY(<All Players>, 3500)` + `CAMERA_LETTERBOX_END()` —— 交还操作，正式开始 |

**要点（本图直接照抄的三条）**
1. 公告一定在 `DISABLE_INPUT()` **之前**——DSA 全程没在"公告/选模式"期间禁输入，因为房主要点按钮。
2. 房主是 `ObjectPlayerScriptName("<1st Human Player>")`（DSA 绕了个结构体的弯路；日冕教程/双兵种直接用这个函数，更干净）。
3. 对话框按钮点一下**自动消失**（教程:382），所以"多选/改选"必须自己 `Show` 一次重画。

## 2 本图的实现（没有运镜）

### 2.1 三段与代码

| 阶段 | 触发 | 代码 | 效果 |
|---|---|---|---|
| ① 锁视角 + 公告 | 节点第一次求值（≈进游戏 1 秒） | `ChoukaStartBegin()` | `MOVE_CAMERA_TO("center")` + `PLAYER_CAMERA_MOVE_TO(Player_N,"center")` → `LOCK_CAMERA(1)` + `LOCK_CAMERA_SCROLL(1)` → `exAptHideObjectDetailsArea()`（收掉右下角操作区）→ `exShowLongTextDialog(810, 公告正文, "已阅读", "", "")` → 中心提示 + 公屏 |
| ② 房主配置 | 房主点「已阅读」 | `ChoukaLongText_start()` → `ChoukaStartShowHostDialog()` | 房主：关公告 → 开选择对话框（811）。其他人：关公告 → 公屏"请等待房主选择配置" |
| ③ 正式开始 | 房主点「确认，开始游戏」 | `ChoukaStartConfirm=1` → 下一次求值 `ChoukaStartFinish()` | 写入抽卡范围（`CHOUKA_DRAW_SCOPE`）→ 盲盒倒计时重置成整轮 → `LOCK_CAMERA(0)`+`LOCK_CAMERA_SCROLL(0)` → `ENABLE_INPUT()` → `PLAYER_CAMERA_MOVE_TO(Player_N,"Player_N_Start")`（**视角回自己出生点**，起重机就在旁边）→ 恢复右下角操作区 → 关掉所有公告/配置窗口 → **全图公告房主的选择**（`ChoukaStartBroadcast`） |

等待期间每秒：重新钉一次视角（每 3 秒）＋ 重刷中心提示 + 重认一次房主（席位就绪有先后）。

### 2.2 地图中间那行「请等待房主选择配置」

```lua
CHOUKA_START_CENTER_WP = "center"          -- 本图中心航点就叫 center（3044, 3029）
exShowTextAtPos("请等待房主选择配置", x, y, z + 80, 16776960)
```

- 用 `exShowTextAtPos`（教程:516「在指定地点显示任意内容的漂浮文字」）。
- **为什么不用 DSA 那种 `NAMED_SHOW_INFOBOX`**：那个动作的第一个参数是**具名物体**，
  而本图 `center` 只是个航点、中心岛附近没有具名物体（只有两座中性油井 `centerOil1` / `centerOil2` 在环外）。
  漂浮文字会自己消失，所以每秒重刷一次，观感上等价于常驻。
- 正式开始时停止重刷，文字自然消失，不需要额外删除。

### 2.3 房主配置有哪些选项

`ChoukaStartScopeOptions` 一张表搞定，想加选项直接往表里加（对话框会自动多一行）：

| 按钮 | 含义 | 写入的全局 |
|---|---|---|
| 1 | 箱子包括全部阵营（**默认**，带 √） | `CHOUKA_DRAW_SCOPE = 0` |
| 2 | 抽卡只有自己阵营 | `CHOUKA_DRAW_SCOPE = 1` |
| 3 | **确认，开始游戏** | `ChoukaStartConfirm = 1` |
| 4 | 重新查看公告 | 重开公告（810） |

- 当前选项会在文字后面加「√」（作者指定的写法：`箱子包括全部阵营√`），点 1/2 会把对话框重画一遍。
- **开局资金已从配置页移除**：改成固定值，写在 `00_init.lua` 的 `BASE_MONEY = 5096`（= 2 抽）。
- `CHOUKA_DRAW_SCOPE` 只影响"抽卡时从哪张池子抽"（`12_puredraw_replace.lua` 的 `ChoukaChooseUnit`）：
  - `1` → `ChoukaDrawPoolBySide[自己的阵营]`（默认，和之前一致）；
  - `0` → 四阵营同档合并池（`ChoukaAllSidePool`），T5 仍然是全阵营共用表。

### 2.4 全图公告：房主正在选什么 / 最后选了什么（照 DSA）

房主在这个窗口里的每个动作都要让**全图玩家**知道，靠一个帮手 `ChoukaStartBroadcast(text, seconds)`：

```lua
function ChoukaStartBroadcast(text, seconds)
    _LOG(text)                                  -- 日志（最稳，事后能翻）
    exMessageAppendToMessageArea(text)          -- 左下角消息区（实测能看到，DSA 全图用了 200+ 处）
    exAddTextToPublicBoard(text, seconds or 15)  -- 公屏（能否显示看 mod 版本）
end
```

| 时机 | 播报内容 | 代码位置 |
|---|---|---|
| 房主点选项 1/2 | `房主正在选择：箱子包括全部阵营` | `ChoukaChoice_start` 选项分支（`ChoukaT.hostPicking`）|
| 房主点「确认，开始游戏」 | `房主已确认开局！抽卡范围：…；第一轮盲盒将在 120 秒后刷新` | `ChoukaStartFinish`（`ChoukaT.hostConfigDone`）|

- 播报**只放在关键动作之后**（发钱/开门/解锁相机都做完了才播）：Lua 4.0 没有 `pcall`，
  万一可见通道报错也不会把开局流程带死 —— 这是第三轮"整局没播报"那个坑留下的规矩。
- 两条文案都在 `01_texts.lua`（玩家可见那组），改字只改那里。
- DSA 的对应做法是"逐玩家左下角小字"：`exAddTextToPublicBoardForPlayer(playerName, msg, 10)`（`_02_event_before.lua` 里几十处）
  + `exMessageAppendToMessageArea`。本图先用"对全员一次性播报"（更稳），实测确认逐玩家接口没问题后再改成每人一条也行。

### 2.5 门控：`CHOUKA_GAME_STARTED`

房主点确认之前，「游戏」的计时类/花钱类玩法一律不动，全部看这一个全局开关：

| 脚本 | 门控后行为 |
|---|---|
| `01_income.lua` | 不结算底薪/油井/中央油井 |
| `02_private_box.lua` | 倒计时冻在整轮、回合数不加、不刷箱子 |
| `05_dog.lua` | 不补保底工程师 |
| `06_center.lua` | 不统计中央占领、不刷中央钱箱 |
| `16_buttons.lua` | 顶部按钮栏不建（`ChoukaBtnStage` 停 0） |
| `20_hud.lua` | 照常画，但倒计时那个数是被冻住的 |

另外 `13_frame_loop.lua` 有个**兜底**：进游戏 3 分钟（2700 帧）还没开局（Lua 报错/房主掉线/没人点），
强行 `CHOUKA_GAME_STARTED = 1` + 解锁相机 + 开输入 + 相机回出生点，并在公屏报一句。

### 2.6 盲盒倒计时为什么改成"每秒节点自己数秒"

原来「私有箱」节点是 `interval = 120` 一把梭，节点间隔从**进游戏**开始算；
现在真正开局要等房主确认，两个时间点对不齐（例如房主 90 秒才确认，箱子会在第 120 秒刷、而不是开局后 120 秒）。
所以：

- 节点间隔改成 **1 秒**；
- `02_private_box.lua` 自己每秒把 `CHOUKA_BOX_LEFT` 减 1，减到 0 才开新回合（回合数 +1、刷箱子、重置倒计时）；
- `20_hud.lua` 只负责画这个数，不再自己减 —— 两边永远一致；
- `03_start.lua` 收尾时把 `CHOUKA_BOX_LEFT` 重置成 `CHOUKA_BOX_SECONDS`（= 120）并重启引擎计时器。

### 2.7 对话框回调为什么有个"分发器"

引擎只认两个固定名字的全局函数：`onUserBtnChoiceDialogEvent` / `onUserLongTextDialogEvent`，
**谁最后定义谁生效**。本图现在有两个节点都要用（开局配置、交易市场），所以：

- `03_start.lua` 与 `16_buttons.lua` 里各写了一份**一字不差**的分发器（谁先跑谁建）；
- 各脚本只把自己的处理函数注册进 `ChoukaChoiceHandlers` / `ChoukaLongTextHandlers`；
- 处理函数 `return 1` = 我处理了，`return 0` = 不是我的，交给下一个；
- 注册用标志位卡住（`ChoukaStartHandlersRegistered` / `ChoukaMarketHandlerRegistered`）：
  脚本每次求值都会重新"定义"一遍函数（新对象），不卡住会让处理函数表每秒变长。

## 3 进游戏怎么验（按顺序看）

1. **进游戏 1 秒内**：相机跳到地图正中（`center`），视角被锁住（滚不动、拖不走）。
2. 全屏公告弹出，正文就是作者给的四段；右下角单位操作区不见了。
3. 地图中心有一行黄字 **「请等待房主选择配置」**，每秒重刷一次不消失。
4. 用**非房主**的号点「已阅读」：公告关掉，公屏出现"请等待房主选择配置"，视角仍锁在中心。
5. 用**房主**的号点「已阅读」：公告关掉，弹出「房主配置 · 抽卡hex」，4 个按钮。
6. 点 1/2：对话框重画，被选那行末尾带「√」（默认带在「箱子包括全部阵营」后面）；点 4 会重看公告。
7. 点 3「确认，开始游戏」：
   - 相机在 1 秒内回到**自己的出生点**（起重机旁边）；
   - 视角解锁，可以自由拖动了；
   - 金钱是固定开局资金 5096（配置页不再能改）；
   - 左下角倒计时从 `02:00` 开始往下走，`抽卡等级：Lv.1`，各档概率正常；
   - 顶部按钮栏出现（3 = 交易市场），**抽卡技能这时才发**（单抽 + 十连两个按钮）；
   - 公屏播报"房主完成配置，游戏开始！抽卡范围：只有自己阵营 / 全部阵营"。
8. **第一轮箱子**：开局后再等 120 秒才刷（不是进游戏 120 秒）。
9. 某个号如果一直没单位，开局后每 5 秒判一次，会在「起重机→出生点」之间补 1 个工程师（并给他一条左下角提示）。

### 已知的"未实测推断"（第一件事就核对）

| 项 | 依据 | 万一不对怎么办 |
|---|---|---|
| `MOVE_CAMERA_TO("center",...)` 认航点名 | DSA 用 `MOVE_CAMERA_TO(CAM0,...)`，CAM0 就是航点 | 已同时调 `exCameraAdjustPos(center坐标)` 兜底，二者都会执行 |
| `LOCK_CAMERA` 真能锁住滚动 | DSA `cams/cam4` 用 `LOCK_CAMERA(0)` 解锁 | 已同时 `LOCK_CAMERA_SCROLL`，并每秒重钉一次视角 |
| `exShowTextAtPos` 的持续时间 | 教程只说"漂浮文字" | 每秒重刷，短了也无所谓 |
| `exAptHideObjectDetailsArea` 只是收掉操作区、不影响点对话框 | 教程:233 | 若发现公告按钮点不动，删掉 `ChoukaStartBegin()` 里那两句即可 |
| 房主识别 | `ObjectPlayerScriptName("<1st Human Player>")` | 返回空就退回 `Player_1`；等待期每秒重认 |

> 想照 DSA 那样在开局期间**彻底禁掉鼠标键盘**（`DISABLE_INPUT`）：把 `03_start.lua` 顶部的
> `CHOUKA_START_LOCK_INPUT` 改成 `1`。本图默认 `0` —— 房主要在这两个窗口上点按钮，
> 而"禁输入时脚本对话框还能不能点"没有现成案例可抄，不敢默认开。
