# 自定义图片导入（PNG → WebP → base64）

> 适用：想把 `images/` 下的 png 变成游戏里能用的按钮/面板贴图。
> 参考实现：DSA 自走棋 `dsa_lua/65_code.txt:260-300`（hextechRemoveButton.png 76×46）；
> 官渡之战 30 张打包贴图（`.dsh-tools/mcpwork/out/guanu_lua/*_asset.txt`）。
> 本图工具：`tools/build-ui-assets.js`。

---

## 1. 关键事实：引擎吃的是 WebP，不是 PNG 也不是 DDS

`exTextureCreateFromBase64(base64, compression, generateMips)` 的第一个参数是**图片文件的字节**，
`compression = "DXT5"` 只是"上传到显卡时压成什么格式"。把官渡 30 张贴图的 base64 解出来看：

```
RIFF <size> WEBP VP8L/VP8X ...
```

**全部是 WebP 容器**（不是 `.dds`）。DSA 自走棋嵌的 hextech 按钮同样是 `RIFF....WEBP VP8X`。

所以流程必须是：

```
png  ──ffmpeg──▶  webp  ──base64──▶  lua 字符串  ──exTextureCreateFromBase64──▶  textureId
                                                                                    │
                                            exPackedTextureImageCreate({...}) ◀─────┘
                                                        │
                                                        ▼
                                        TextureName（自定义按钮 / 自定义图片）
```

直接把 PNG 字节塞进去**不保证能用**（引擎的解码器走 WebP 这条路是实测过的，PNG 没人验证过）。

---

## 2. 转换命令（ffmpeg，本机已装）

```powershell
# UI 按钮：必须无损，否则边缘会有压缩噪点
ffmpeg -v error -y -i images/ui/hextechRemoveButton.png `
       -c:v libwebp -lossless 1  out/ChoukaUiBtnRemove.webp

# 颜色块（代码生成，不需要任何 png 文件）：深底 + 3px 浅框 + 居中 66×66 色块
ffmpeg -v error -y -f lavfi -i "color=c=#101418:s=96x96" `
  -vf "drawbox=x=8:y=8:w=80:h=80:color=#C9D3DE@1.0:t=3,drawbox=x=11:y=11:w=74:h=74:color=#181C22@1.0:t=fill,drawbox=x=15:y=15:w=66:h=66:color=#E63232@1.0:t=fill" `
  -frames:v 1 -c:v libwebp -lossless 1  out/ChoukaUiColorRed.webp
```

体积参考：76×46 的按钮 png 4.6 KB → webp 3.1 KB → base64 4.2 KB；8×8 纯色 webp 38 B → base64 52 字符。

## 3. 生成出来的 Lua 长什么样

`tools/build-ui-assets.js` 生成 `scripts/lua/chouka/95_assets/03_ui.lua`，每张图一段：

```lua
-- ChoukaUiBtnRemove
local base64 = "UklGRiwDAABXRUJQVlA4WAoAAAAQ..."

if ChoukaUiBtnRemove == nil then
    local compression = 'DXT5'
    local generateMips = 0
    local textureId = exTextureCreateFromBase64(base64, compression, generateMips)

    ChoukaUiBtnRemove = exPackedTextureImageCreate({
        Texture = textureId,
        CoordsX = 1, CoordsY = 1,
        DimensionsX = 76, DimensionsY = 46,
        TextureDimensionsX = 76, TextureDimensionsY = 46,
        Rotated = 0
    })
end
```

要点：

| 项 | 值 | 说明 |
|---|---|---|
| `if X == nil` 守卫 | 必须有 | 节点每秒都会重新求值，没有守卫就会每秒建一次贴图 |
| `DimensionsX/Y` | **图片原始像素**（76×46） | 别写 104；官渡的图是 104×104 才写 104 |
| `CoordsX/CoordsY` | `1, 1` | 单贴图图集，官渡同款；DSA 写的是 `0, 0`，两边在实测里都能出图 |
| base64 字符串 | 引号或 `[[ ]]` 都行 | base64 里没有需要转义的字符 |

按钮侧用法（本图 `70_bang/35_ally_panel.lua`）：

```lua
function ChoukaPanelIconClose()
    if ChoukaUiBtnRemove ~= nil then return ChoukaUiBtnRemove end
    return "JUA_TBuster_LeaveBurrow"      -- 贴图节点没跑起来时的兜底
end
```

`TextureName` 直接接受 `exPackedTextureImageCreate` 返回的对象（官渡、DSA 都是这么用的）。

## 4. 现有图片清单（`images/ui/`）

| 全局名 | 源文件 | 尺寸 | 用途 |
|---|---|---|---|
| `ChoukaUiBtnUndo` | `hextechUndoButton.png` | 76×46 | 面板「返回」 |
| `ChoukaUiBtnUndoHover` / `Pressed` / `Disabled` | 同名 + 后缀 | 76×46 | 预留（海克斯） |
| `ChoukaUiBtnRemove` | `hextechRemoveButton.png` | 76×46 | 面板「关闭」 |
| `ChoukaUiBtnRemoveHover` / `Pressed` / `Disabled` | 同名 + 后缀 | 76×46 | 预留（海克斯） |
| `ChoukaUiColorRed/Blue/Yellow/Green/Cyan/Purple/Orange` | **无源文件**，ffmpeg `drawbox` 代码生成「边框+内衬+色块」| 96×96 | 结盟面板的玩家头像（显示成 84×84，色块约 58 px）|

加新图只需在 `tools/build-ui-assets.js` 的 `BUTTON_IMAGES` 里加一行 `{png, global, note}`，
然后 `node tools/build-ui-assets.js`，再在 `tools/sync-scriptsdata.js` 里确认新文件已登记（同文件内的追加不用改 NODES）。

## 5. 坑

1. **节点体积**：单节点 payload = `00_alert.lua` + `01_texts.lua`（14629 B）+ 资产。
   硬上限 65536 B，警告线 64512 B。`03_ui.lua` 现在 40 KB，余量约 9.5 KB —— 再加图就得拆节点。
2. **必须无损**：`-lossless 1`。有损 webp 会让 UI 按钮文字边缘发糊。
3. **尺寸要跟 `SizeX/SizeY` 对上**：hextech 这两张是 76×46 的横条，面板里的 `SizeX/SizeY` 就得是
   `76/46`，按 46×46 摆会被拉扁。
4. **贴图节点要 `interval=1` 且 `deactivateUponSuccess:false`**：贴图只能在第一次求值时建，
   节点停掉就没了。
5. **别用 `_LOG` 之外的字符串当 base64 载体**：base64 里出现 `--` 会被当成 Lua 注释截断（正常
   base64 不会出现 `--`，但拼接字符串时小心）。
6. **官方地图的做法可以照抄**：DSA 自走棋的 `analysis/hextech_frames_black.py` 是它的离线转换脚本，
   产出就是 webp base64；我们这边等价物是 `tools/build-ui-assets.js`（ffmpeg 版）。
