# 01 · 三张源地图机制拆解

> 全部结论来自实测：用 Ra3MapEditor MCP 打开三张图，导出脚本树 / 脚本 XML / 高程图 / 对象清单，
> 再离线做水域连通块与隔断厚度计算。凡是「作者注释」的内容都在脚本 `Conmment` 字段里原样写着。

### 1.2 地形拓扑（实测，改造前）

整张图是**蜂窝状**的：陆地与水域都是六边形格子，彼此被 **宽 17~20 格的陆地土埂**隔开
（≈170~200 世界单位，全部由 `IL_SEACLIFFWALL01/02/04/05` 共 368 个海崖墙模型镇住）。

```
水域一共 12 块 + 1 个单格噪点：
  外圈 6 块（大，30k~49k 格）：A B C D E F
  内圈 6 块（小，各 ≈14.7k 格）：G H I J K L
```

- **外圈 6 块**：每块**正中装一个玩家岛**（岛上有 1 `OreNode` + 1 `OilDerrick`）。
  也就是说「我的海」就是这一整块，别人进不来 —— 这就是「**海域有限**」的全部含义。
- **内圈 6 块**：夹在中心岛与玩家岛之间、两两相邻岛屿之间的空塘，没有陆块，也没有人用。
- **中心岛**：中立，带 1 `OreNode` + 1 `OilDerrick`，是全场唯一的地面争夺点。

几何方位（世界坐标以可玩区左上为 0,0）：

| 水域（外圈） | 中心 | 里面的岛 / 玩家 |
|---|---|---|
| F（W5） | (3060, 570) | 顶岛 → Player_3，出生 (3047, 863) |
| D（W3） | (5185, 1420) | 右上岛 → Player_2，出生 (4932, 1947) |
| B（W1） | (5170, 4735) | 右下岛 → Player_1，出生 (4927, 4110) |
| E（W4） | (3045, 5555) | 底岛 → Player_6，出生 (3044, 5193) |
| A（W0） | (890, 4825) | 左下岛 → Player_5，出生 (1152, 4111) |
| C（W2） | (885, 1450) | 左上岛 → Player_4，出生 (1151, 1946) |
| — | 中心岛 (3045, 3045) | 中立 |

6 个岛按 60° 均匀分布（方位角 30/90/150/210/270/330°），中心岛在正中。
外圈 6 块水域两两相邻成一个**环**：`F–C–A–E–B–D–F`。

### 1.3 脚本构成（88 条）

| 归属 | 脚本 | 作用（来自作者注释 + 实测参数） |
|---|---|---|
| 全局 | `欢迎二创` | 一段长注释式的作者自述，`deactivateUponSuccess` |
| 全局 | `MUSIC` | 音乐 |
| 全局组 `油田重铸`（**组已停用**） | `rebuild1` / `rebuild2` | 监视命名单位 `Center2` 被摧毁 → 3ms 后在中立 `Center` 航点重建 `oilderrick`（中立的可争夺油井） |
| 全局组 `修复基地车脚本人机BUG` | `计时1秒` / `删除电厂` | 每秒 `UNIT_KILL_ALL_IN_AREA` 清掉 `DieAreaBUG` 区里的东西（防止 AI 的 MCV 跑飞/卡住） |
| 全局组 `地图介绍` | `TL1`~`TL4` | 开局滚动的图文规则介绍（`SET_MILLISECOND_TIMER` 串起来的分页） |
| 每个玩家 ×6 | `Money` | **每 1 秒**判定：在 `Total` 区里「拥有 ≥N 个各阵营 MCV / MCV-naval」（4 个 OR 分支：苏/日/神州/盟）→ `PLAYER_GIVE_MONEY 8`。即**有展开的 MCV（建造工厂）就 +$8/秒**，是这张图唯一的经济来源 |
| 每个玩家 ×6 | `View Get` / `View Lost` | 经典「间谍卫星系统」互锁循环：有 **4 座建造工厂** → 全图常亮；失去 → 撤销；两条脚本互相 `ENABLE_SCRIPT` 形成循环（作者注释里明确警告持续脚本互相激活会出黑屏 bug） |
| 每个玩家 ×6 | `MCV传送登场` ×3 / `龙船闪亮登场` | 开局 MCV 超时空传送 / 龙船从天而降的入场表演 |
| 每个玩家 ×6 | `授权AI` / `AI直接给基地` | 给该玩家挂 AI 人格、必要时直接塞基地 |
| 每个玩家 ×6 | `Allied__n` / `Soviet__n` / `Janpan__n` / `Celestial__n` | 按阵营生成开局旗帜/装饰（`CREATE_UNNAMED_ON_TEAM_AT_WAYPOINT_WITH_ORIENTATION`，全场 90 次调用的大部分都在这儿） |

**一句话概括**：这是一张**完全没有「回合」概念**的即时战略小块地 ——
收入由 MCV 数量驱动、视野由建造工厂数量驱动、唯一的公共资源点就是中心那座会重建的油井。

### 1.4 map.str 里的口径

- 欢迎语 + 三条规则：展开 MCV 拿视野 / 海域有限 / **有 MCV 就 +$8 每秒**。
- 文案里提到「若 MCV 存活，玩家拥有一个隐藏油田」，与 `Money` 脚本的实现一致。

## 2 盲盒图：《（cor）盲盒高原v1.6正式版》

### 2.1 尺度

700 × 700 格、**border = 0**、高程 150~310（**整张图都是陆地高原，没有水**）、
101 个对象、19 个玩家位、15 条脚本。

### 2.2 抽卡（盲盒）机制 —— 全部用原生触发器实现，**没有一行 Lua**

主角是全局脚本 `盲盒生成`，`EvaluationInterval = 120`（每 120 时间单位结算一次）：

| 动作 | 参数 | 含义 |
|---|---|---|
| `CREATE_..._AT_WAYPOINT` | `moneycrate` × 4，航点 `a1`~`a4`，队伍 `PlyrCivilian/teamPlyrCivilian` | **中立金钱盲盒**，放在 4 个固定点，谁先开谁拿 → 争夺型 |
| `CREATE_..._AT_WAYPOINT` | `unitcratenew` × 12，航点 `h1`~`h12`，每个玩家 2 个 | **单位盲盒**，按玩家私有 → 保底型 |
| `OBJECT_CREATE_RADAR_EVENT` | `z1`~`z4`，类型 0 | 在小地图上持续给盲盒点位打雷达提示 |
| `DISPLAY_COUNTDOWN_TIMER` / `SET_MILLISECOND_TIMER` | 计数器 `time` | 场上倒计时显示「下一箱还有多久」 |

配套还有：

| 脚本 | 逻辑 |
|---|---|
| `初始化` | 全场 +30000 资金、`MAP_REVEAL_ALL_PERM` 全图常亮、启动倒计时、启用 `计时器`、给 z1~z4 打雷达 |
| `计时器`（`EvaluationInterval=120`） | 每轮重置 `time` 计时器并重新打雷达 |
| `固定收入__n` | 每 1 秒：**造了 `sovietcrane`（起重机）→ +$100/秒** |
| `起重机科技__n` | 造了 `sovietconstructionyard` → 允许造兵营 + 电厂；否则禁止（一条「科技锁」用法） |

**要点**：所谓「抽卡」在引擎层面就是**箱子对象本身**（`moneycrate` / `unitcratenew`）
—— 箱子里开出来什么由游戏规则决定，地图作者只负责**在哪儿刷、多久刷一次、归谁**。
随机性免费，点位与时序才是设计。

### 2.3 与「一块地」的差异

- 没有海、没有分岛、没有回合概念，纯靠箱子节奏 + 固定收入撑经济。
- 收入曲线是**作者完全可控**的（不需要矿场），这正是把它缝到「一块地」的理由 ——
  因为一块地把矿场油井砍掉之后，经济本来就要靠脚本给。

## 3 海克斯图：《DSA_ggz自走棋》

基准代码 `E:\Ra3_AutoChess\DSA_ggz`（本工作区内的 `日冕地图lua例子\DSA_ggz自走棋` 是同一份）。
设计文档：`analysis/自走棋海克斯系统/海克斯符文系统设计.md`（1317 行）。

### 3.1 它是怎么玩起来的

- **自走棋**：玩家不出兵打仗，只**造建筑/单位**，单位每回合自动在地图中央打一场。
- **经济**：电厂 = 油井 = 收入，每阶段电厂上限 5 / 7 / 9 / 11。
- **科技锁**：开局只能造 T1；T2/T3/T4 分别在第 6 / 12 / 19 回合解锁；
  摧毁对方外塔可以**提前解锁**。
- **回合引擎**：`RoundLuaManager`，`huihe/start` 每回合先把 `start` 计时器设 60 秒，
  再按回合数 `lvc` 追加（`T(n)=60+⌈n/2⌉`，二阶后 `60+5⌈n/4⌉`），所以回合时长不是固定值。

### 3.2 海克斯符文系统（要缝的东西）

**流程**：

```
回合开始 → HextechRune:OnRoundBegin(lvc)
  ├─ 模式开关开？(房主选项 / 「开启随机箱子」)
  ├─ 当前回合 ∈ {3,10,18,27}（按次数 N 截取）？
  └─ 对每个存活玩家：
       ① 全场先抽一次稀有度（银/金/彩），连回合号写入该玩家事件队列
       ② 只提示「有未选的海克斯，按 J 展开」，不自动弹卡页
       ③ 玩家按 J → 现场筛池（去重 + 每人独占 + 兵种标签）抽 3 个 → 开卡页
       ④ 玩家点选 → 记入 PlayerOwnedRunes / PlayerOwnedRuneIds
       ⑤ 登记到回合回调 → 每回合出兵时按兵种给己方单位上 buff
       ⑥ 公共面板播报「玩家X获得了符文Y」
```

**稀有度概率表**（每次事件全场共用同一档）：

| 发放 | 回合 | 彩 / 金 / 银 |
|---|---|---|
| 第 1 个 | 3 | 10% / 40% / 50% |
| 第 2 个 | 10 | 15% / 42% / 43% |
| 第 3 个 | 18 | 15% / 42% / 43% |
| 第 4 个（可选） | 27 | 30% / 50% / 20% |

**池子规模**（2026-10-19 口径）：67 条 —— 银 24 / 金 23 / 彩 20。
覆盖进攻 / 防御 / 经济 / 召唤 / 功能五大类；通用卡会**按兵种展开成 4 个独立候选**
（步兵 / 载具 / 飞机 / 海军），并带阵营限制、禁用模式过滤、不重复名单等规则。

**技术实现要点（对我们最重要）**：

| 约束 | 内容 |
|---|---|
| Lua 版本 | **Lua 4.0**，没有 `goto`、没有位运算、`table.unpack` 不存在 |
| 闭包 | **不支持闭包访问外层局部变量** —— 回调要用的外层变量必须走参数或提升为全局 |
| 执行标记 | 每个执行块必须以 `#!ra3luabridge` 开头，否则 RA3LuaBridge 不执行 |
| 脚本存放 | `lua/*.lua` 是 `ScriptsData.json` 的**拆分**；地图实际加载的是 JSON，改完要同步 |
| payload 上限 | 单个 payload ≈ **64KB**，超了会被截断并报 `last token read: '<eof>'`；超 64512 B 时同步工具自动去注释，去注释还超就必须拆节点，而**新节点要先在地图脚本树里加好** |
| nil 键 | 本图 Lua 用 `nil` 当键查表会直接抛错，查表前必须判空 |
| UI 素材 | 自定义图片走 `exTextureCreateFromBase64(b64,"DXT5")` → `exPackedTextureImageCreate` → `IconId`；素材是 webp（如 huohuo.webp 700×700 → 126×126 → 7722 B base64） |
| 卡面 | 银/金/彩三档边框各一张 512×512 png（`augmentcard_frame_silver/gold/prismatic`）+ relics 图标 120/256 px |
| 面板 | 顶部按钮 5 查已持有符文；J 键开三选一；公共面板广播 |

### 3.3 它的「抽卡」（PureDraw）也值得抄

DSA 里另有一套 **PureDraw / Lucky Crate** 抽卡模式：`CrateEnabled`（"抽卡模式已启用"）、
`PureDrawQuota`（"剩余生产余额，每段围墙代表 1 点，每 3 回合补满"）。
它和盲盒高原的箱子是**同一件事的两种做法**：
- 盲盒高原 = 地图上刷实体箱子，玩家跑过去开；
- DSA = 玩家点 UI 直接消费额度抽卡。
两种我们都能用，而且不冲突 —— 见方案文档的分层建议。

## 4 三张图的拼接口子（结论）

| 维度 | 一块地 2.0 | 盲盒高原 | DSA 自走棋 |
|---|---|---|---|
| 时间轴 | **无回合**，只有秒表 | 有 120 单位的补给节拍 | **强回合制** `lvc` |
| 经济 | MCV 数量 × $8/s | 箱子 + 起重机 $100/s | 电厂数量 |
| 公共争夺点 | 中心油井（会重建） | 4 个中立金钱箱 | 中央战场、外塔 |
| 随机性 | 无 | **箱子开出来的东西** | **海克斯三选一** |
| 脚本技术 | 纯原生触发器 | 纯原生触发器 | **Lua 4.0 bridge** |
| 玩家数 | 6 | 6 | 6（分天使/恶魔两方） |

**能直接搬的**：盲盒的「箱子点位 + 节拍 + 雷达提示」是纯原生触发器，搬到一块地上零风险。
**需要改造的**：海克斯整套依赖「回合」这个心跳，而一块地没有回合 —— 这是方案要解决的第一个问题。
